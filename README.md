# Daily Expense Tracker

This is a Python-based expense tracking system that records daily expenses, groups them by category, and calculates total spending.

## Technologies Used
- Python

## Features
- Add multiple expense entries
- Categorize expenses
- Calculate category-wise spending
- Calculate total expenses
- Interactive console-based system

## Concepts Used
- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input
- Arithmetic Operations

## Project Type
Python Expense Management Project
